# 段落库：原文参考

规则并不一定那么有效。有时候写出来对得上规则，可读起来还是不像，这时候更适合读一段原文，看原文具体的写法。

这个文件夹负责保存用于参考的原文段落。

## 文件夹内容

```
passages/
├─ README.md    本文件，讲用法与增补流程，可以进版本库
└─ quotes.md    原文本身，不随仓库分发
```

`quotes.md` 是原著正文的摘录，著作权不属于本仓库，公开分发版本也不包含此文件。你可以自己建一份，在本地按下面说明的方式添加语料。只要格式对得上，本仓库的用法说明就全部适用。

## quotes.md 使用说明

开头三句说明，然后每段四块，以下为使用模板：

```markdown
# 原文段落库

按编号排。每段四块：标题、两行元信息、原文、三条可以注意的地方。
要加一段：接下一个编号，照现有任意一段的四块照抄一遍。

## P01 冷开场·异象

- 出处：第三部《黑月之潮》 · 前传 冰海王座 楔子
- 类型：开场与异象

> 第一段原文……
>
> 第二段原文……

**可以注意的地方**

- 第一条……
- 第二条……
- 第三条……
```

元信息需要两部分：出处精确到卷和章，类型用一个词或短语概括。**不需要字数与段数。** 

## 怎么用

1. **按类型找。** 目录里每行一条：编号、标题、卷、章。先按你此刻要写的东西分类型寻找。
2. **整段通读。** 不要只读一句。画面的节奏在段与段之间，摘一句看不出任何东西。
3. **只看停顿与换气。** 第二遍不看内容，只数：哪一段是单句、哪一段很长、长段之后紧跟的是什么。
4. **合上原文再写。** 拿着刚读到的节奏去写自己那一段，不要抄句子，也不要改写它。抄和改都会露痕迹。

## 怎么往里加

1. 打开 `quotes.md`，把下一个空编号写上去，标题用一个短语概括这一段的功能，不要写"精彩片段"这种意义不明的词。
2. 抄两行元信息：出处精确到卷和章（章名照抄，不要简写），类型用一到四个字。
3. 逐段粘原文，每段前面加 `> `，段与段之间空一行 `>`。按照原文逐字摘抄，不要改动、删减、拼接。
4. 写三条"可以注意的地方"。每条指向一个可执行的动作，不要写"写得很好""氛围浓厚"。好的例子：这段第一句先给坐标不给情绪；长段之后紧跟一句十三字的骂；到第三段才让人物说话。
5. 在文档上面的目录表里添加新内容。

## 一篇合格的段落要满足

- 能独立读懂。不需要前后文也能看明白发生了什么。
- 有完整节奏。至少有一个长段和一个短段，最好有对话。
- 只承担一种功能。既是打斗又是抒情又是群像的段落，读的时候容易抓不住要点。
- 长度在五百字以上。太短的话参考价值不足。
