# 《龙族》情节结构与人物塑造：可复用模板

本文件与 `style.md` 配套。`style.md` 管句子和段落，本文件管“一章怎么搭、一个人怎么立”。
所有数据取自三部正文全量统计（已剔除章节标题与脚注行），模板中的槽位写成可直接填的格式，末尾给验收标准。

## 一、全书骨架模板

### 1.1 五段式（三卷共用）

```
〔异象段〕 0.5–1 章：一段与主角无关的高位叙述（神、王、怪物、百年前的屠杀），结尾必须死一个人或毁一件东西。
〔日常段〕 2–4 章：主角在低处生活，穷、怂、被嘲笑、有具体烦恼（补考、生活费、喜欢的女孩），把“人间”的锚打下去。
〔并线段〕 4/5–4/5 章：两条线交替推进——主角线（查真相、被追杀、被迫上场）与高位线（幕后者的棋局、家族会议、敌方集结），两条线的信息差就是悬念。
〔献祭段〕 3–5 章：连续高潮。每一章都要付一次代价（死一个人、失一种能力、毁一座城），主角每赢一次就少一点人性。
〔回落段〕 1 章（尾声）：大战被新闻化、被误传、被遗忘；主角回到一个具体的小场景（吃面、看演出、坐车），用一个极短动作收全书。
```

**验收**：全书至少 2 处“异象段”（开篇与中段各一次）；献祭段内不得出现两章连续无人死亡或无人失去能力；尾声不得出现“从此以后”式总结句，必须以具体动作或具体物件结束。

### 1.2 三卷的差异化配置

| | 第一部 | 第二部 | 第三部 |
|---|---|---|---|
| 高位线强度 | 中（父亲／学院秘密） | 中（学院政治＋家族） | 强（神代复活＋三国棋局） |
| 日常段占比 | 高（约 35%） | 中（约 25%） | 低（约 15%，且日常只作缓冲） |
| 死亡密度 | 每 3 章 1 人 | 每 2 章 1 人 | 每章 1–2 人，高潮章成群死 |
| 主角主动性 | 被动卷入 | 被推着走 | 主动选择赴死 |
| 结尾温度 | 温（回家） | 凉（发现真相） | 冷（告别演出） |

**用法**：写“少年初入异世界”用第一部配置；写“少年开始查真相、发现自己也是怪物”用第二部配置；写“少年成为局中人、替别人去死”用第三部配置。

## 二、单章模板

### 2.1 章首钩子六型（按统计占比从高到低）

**A 型·地标开场**（第三部高频）：一句地名／时间，独立成段，不解释。

规则：地名句 ≤25 字，独立成段，下一段立刻给一个具体感官细节（温度、气味、声音），第三段才出人。

**B 型·动作开场**：主语＋一个正在进行的身体动作，且这个动作后来有含义。

规则：动作必须是“静止类”或“收束类”（站、坐、发呆、扣上、合上），不许用“冲进去”“大喊”这类高能耗动作开场。

**C 型·状态判断开场**：一句断言主角生活出了问题。

规则：只写“察觉”，不写“为什么”，把原因压到本章第 3 段之后。

**D 型·引语开场**：直接上对白，且这句话本身是个坏消息或问题。

规则：引语段前不加任何铺垫段；引语里必须有一个具体名词（数据库、档案、书）。

**E 型·观察者开场**：一个高位者（博士、校长、家主）在看着某人，读者跟着他的视线看。

规则：观察者的身份先给，被观察者的惨状后给，两句之内完成。

**F 型·异象开场**：一段不可能发生的自然现象。

规则：全书只用 2–3 次，用在卷首或卷末。

**分配建议**：一卷 20 章，A 型 4–6 次、B 型 4–5 次、C 型 2–3 次、D 型 4–6 次、E 型 2–3 次、F 型 1 次。

### 2.2 章末落点四型

**甲·物件句**（最冷）：只留一件东西。

**乙·极短对白**：一句 5–15 字的台词收尾，不加叙述。

**丙·判断句／格言句**：一句断言，把本章意义钉住。

**丁·日常回落**：把惨烈事件放回生活尺度。

**规则**：一章只能用一个落点，不许“物件句＋格言句”叠加；高潮章用甲或乙，缓冲章用丙或丁；第三部甲、乙型占比应高于前两部（章末段平均 64.5 字，但落在极短句上的章更多）。

**验收**：抽 10 章，若章末段全是 40 字以上的说明性长段，判不合格——说明作者不敢停。

### 2.3 章内节拍（一章 18000 字的标准配比）

| 节拍 | 字数占比 | 内容 | 硬要求 |
|---|---|---|---|
| 起 | 10% | 钩子＋场景落地 | 不解释设定 |
| 承 | 30% | 日常／任务推进，穿插一次闲笔（吃饭、买衣服、打游戏） | 闲笔必须含一个后文会用到的物件 |
| 转 | 20% | 意外：敌人出现／真相露一角／同伴背叛 | 转折点前后各留一段 ≤15 字的独立短段 |
| 高潮 | 30% | 打斗或对峙，三拍：占上风→被反转→付代价 | 每 3–5 句插一句短句独立成段 |
| 落 | 10% | 收拾现场＋一句钩子 | 不许总结感悟 |

## 三、高潮段落模板

### 3.1 五拍结构（以“须弥座誓师”与“天谴”为原型）

```
第一拍·集结：把规模写出来。用三类可数量化的东西——人数（数千人）、器械（三联速射炮、液态汞弹头、炼金鱼雷）、环境（探照灯、直升机群、水警船群）。
第二拍·仪式：让最高位者做一件极简的动作（鞠躬、举手、摘帽），台词压到 4–8 字，且是请求而非命令。
第三拍·反转：仪式进行到一半，情报打断（“极渊中发生3.2级轻微地震，神葬所正在苏醒”）。
第四拍·代价：立刻死一个有名有姓的人，或废掉一样刚建立的希望。
第五拍·静场：所有人不说话，只留一个声音（雨声、乐声、心跳）和一个动作（点烟、合眼、转身）。
```

**禁忌**：高潮段里不许出现“他明白了”“他终于懂得”这类顿悟句；顿悟改由一个动作承担（把烟点上、把刀插回鞘、把伞撑开）。

### 3.2 打斗段落的句子配比

- 动作句：短，8–15 字，主语明确，动词前置。
- 效果句：中，20–30 字，写“打中了什么、坏了什么”，不写“很痛”。
- 视角句：每 4–6 个动作句插 1 句旁观者的反应（“恺撒微微吃了一惊，不知什么时候这个废柴的眼神变了”）。
- 环境句：每 8–10 句插 1 句天气或地形（雨、火、井盖、海水），用来控制节奏而不是抒情。

**验收**：一段 300 字的打斗里，若句长最大值与最小值差距不到 3 倍，判节奏平；若连续 6 句都在 20 字以上，判拖。

### 3.3 死亡的处理

三种写法，按角色重要度选：

1. **龙套**：一句带过，用统计口吻（“至少几百只尸守”）。
2. **配角**：给一个生前的小癖好，再让他做一次这个动作，然后死。
3. **重要角色**：不写死的瞬间，写死后别人怎么用一件小事想起他（开车时回头、点单时多要一份、唱一首他教过的歌）。

**验收**：重要角色死亡后 3 章内，必须出现至少 1 次“无意的怀念动作”，且这个动作不得被解释。

## 四、悬念铺设与回收

### 4.1 三层悬念

| 层 | 载体 | 铺设时机 | 回收时机 | 例 |
|---|---|---|---|---|
| 物件层 | 一柄没刀镡的刀、一本写拉丁文的旧课本、一串青翠葡萄 | 主角第一次遇险时随手出现 | 同卷内 3–8 章后 | 伞里抽出御神刀 |
| 身份层 | 某人的姓氏、口音、胎记、不会用的餐具 | 该角色第二次出场 | 下一卷 | 主角的老师其实是敌方家主 |
| 预言层 | 一句听不懂的话、一段异国语言、一句歌词 | 卷首 | 全书结尾 | “さよなら”在尾声被唱出来 |

**规则**：一章内最多推进 2 层；物件层必须在本卷回收，身份层可跨卷，预言层只在全书首尾各出现一次。

### 4.2 信息差表（写每章前先填）

```
读者知道 / 主角不知道：______  ← 制造紧张
主角知道 / 同伴不知道：______  ← 制造孤独
所有人都不知道 / 反派知道：______  ← 制造恐惧
```

**验收**：每章至少占一格；连续 3 章三格全空，判该章为填充章，删或并。

### 4.3 回收节奏

- 短回收：铺设后 1–2 章内兑现，用于小道具（一包烟、一张名片）。
- 中回收：3–8 章，用于能力、身份线索。
- 长回收：跨卷，用于预言、血统、上一代的恩怨。

**验收**：每 10 章至少完成 1 次中回收；若 15 章内无任何回收，判伏笔失效。

## 五、人物塑造模板

### 5.1 出场四步（顺序不可颠倒）

```
第一步·异常物件（1 句）：先给一个不该出现在这个场景的东西。
第二步·外貌白描（1–2 句）：只写 3 个特征，颜色优先（金发、海蓝眼瞳、纯白小夜礼服、紫罗兰手帕）。
第三步·身份落地（同段末或下一段首）：把姓名和头衔一次给全，不给第二遍。
第四步·旁人失态（1–2 句）：用一个旁观者的失礼反应替代作者的赞美。
```

**验收**：出场段里若出现“英俊”“气质非凡”“与众不同”这类评价词，判不合格——必须换成可指认的颜色、材质、动作，或旁人的失礼。

### 5.2 反差出场（用于喜剧角色／伪装角色）

先给一套错误身份的完整表演，再一句戳破。

规则：错误身份要演满 3 句（含外语、切口、装可怜），戳破要由对方（不是本人）完成，且戳破句必须比对白更短。

### 5.3 性格外化四件套（每个主要人物配齐）

| 外化手段 | 要求 | 例 |
|---|---|---|
| 口头禅 | 3–6 字，一卷内出现 ≥5 次，且每次语境不同 | “人生苦短，必须性感！” |
| 身体癖好 | 一个可重复的小动作 | 把麦片泡进牛奶里，搅拌 |
| 对物件态度 | 对某样东西异常珍惜或异常浪费 | 用手帕擦手后丢掉／把双煎蛋推给别人 |
| 恐惧源 | 一个具体的东西，不是抽象概念 | 怕被人看见自己在哭／怕坐电梯 |

**验收**：抽该人物的 5 段戏，若 5 段里四件套出现不到 2 件，判人物没立住。

### 5.4 群像三角配置（每支小队必备）

```
A 怂：能力低、话多、负责吐槽与承接读者视角，是“怕”的容器。
B 冷：能力高、话少、负责执行与背锅，是“忍”的容器。
C 耀：能力高、话多、负责摆姿态与破局，是“傲”的容器。
```

三者必须满足：A 与 B 有一次单独相处的沉默戏；A 与 C 有一次互相拆台；B 与 C 有一次并肩作战且不说话。

**验收**：若三人中任意两人在全书没有一场只有两人的戏，判群像是拼盘。

### 5.5 强者软肋（防止强者变成工具）

每个强者只给一条软肋，且必须是“低处”的东西：一只象龟、一碗拉面、一个不会写的字、一个不肯改的口音。
写法：让他在最不该分心的时刻想起它，只用一句，然后立刻回到战斗。

**验收**：软肋在全书出现 2–4 次，且最后一次必须是“软肋救了他”或“软肋害了他”，不许只用来说煽情。

### 5.6 人物弧线（三次选择）

```
第一次选择（全书 1/4 处）：为了自保而撒谎／逃跑 → 造成一个小恶果。
第二次选择（全书 1/2 处）：为了别人而牺牲一件自己的东西（钱、机会、名誉） → 得到一句不咸不淡的谢。
第三次选择（全书 4/5 处）：为了一个信念而放弃生命或身份 → 无人知晓，或被误传成别的样子。
```

**验收**：三次选择必须各自有一个“可指认的代价物”（具体到金额、物件、身体部位）；若三次代价都是“心理上的难受”，判弧线空转。

## 七、常见崩坏与修法

| 症状 | 病因 | 修法 |
|---|---|---|
| 中段读者流失 | 承段太长、无代价 | 把承段砍 1/3，在第 40% 处塞一次“死人”或“失能” |
| 高潮不燃 | 集结拍缺数量、反转拍缺情报 | 补 3 个可数名词（人数、器械、距离），补 1 句情报打断 |
| 人物像工具 | 只有功能没有癖好 | 补四件套中的“身体癖好”与“恐惧源” |
| 情感不落地 | 用顿悟句代替动作 | 删掉“他明白了”，改写成一个具体动作 |
| 悬念失效 | 只有铺设没有回收 | 建伏笔表，每 10 章强制回收 1 条中线索 |
| 群像散 | 缺两人独处戏 | 给每对关系补一场“只有两人、且不说话超过 3 段”的戏 |
