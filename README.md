# longzu · 龙族文风写作 Skill

希望这个skill可以帮助你实现想象中的文字。

**非官方，非授权，仅用于写作辅助与参考，禁止用于商业用途**

## 作者的碎碎念

高中的时候看了三遍龙族，包括新旧两版和龙四龙五，对江南老贼可谓又爱又恨。每一个衰小孩大概都共情过路明非，也羡慕他有拯救世界的精彩故事。

至今为止，我对《龙族》的笔法印象依旧很深，而且一直学不会，只好希望能寄托在AI身上了。于是给AI喂了龙族前三部的正文，蒸馏出了这个skill，迭代了几版，最终有了现在这个仓库。

它依旧有很多不足，更不可能完全模仿江南，只能用数据去分析那些感性的东西，试着去拼凑一段有“龙族味”的文字。

如果你觉得它还不错，可以给仓库点一个star。如果你有余裕，也可以贡献一些你的数据。

> **我们都是小怪兽，有一天会被正义的奥特曼杀死**。

## 功能

这是一个AI agent skill，更具体地说，是一个给长篇小说写作 AI 使用的**风格规格书**，负责回答三种问题：

1. **动笔前**：这一章该怎么起名、第一段怎么写、对白占多少、章末怎么结尾。
2. **写的时候**：这个词是《龙族》里会出现的吗？这句该长还是该短？这段玩笑是不是太扁平？
3. **写完改稿**：为什么"句子都对但不像"？为什么高潮不燃？为什么插叙读起来像资料？

- **不是**《龙族》的同人续写模板。它只提供写作规则，不包含任何可以直接使用的句子/文段。
- **不是**《龙族》续写专用的技能。只记录了江南写作的方法，没有对《龙族》的剧情、人设、世界观进行任何解析。
- **不是**文学评论。他不对《龙族》进行任何评判，只使用可核对的数字或可查证的原文来生成判断。
- **不包含**原著正文。仓库里只包含用于论证规则的引用片段，没有整章文本。

## 构建方法

所有条目都来自同一套流程，可以复现：

### 1. 语料转换

使用语料为《龙族》三部正文的txt文件，由AI进行 txt（GBK）→ UTF-8 Markdown 格式转换。统一去除空行、`# 书名`、`## 章节标题`、正文每段后加空行。

**校验**：md 数与 txt 数一致；三份文件的 U+FFFD 计数均为 0，确认无乱码；首尾完整。

### 2. 段落索引

由于行号漂移，所以所有定位都用**正文段落数组索引**来排除空行、书名行、标题行后的第 N 段。标题行另存一张表（原始行号 + 标题文本），用来检查某段属于哪一章。

### 3. 提取与取样

- **词频/密度统计**：对三卷分别计数，换算成"每万字频次"，再进行横向对照。
- **窗口取样**：按段落索引切出 150–2,000 字的连续片段，人工读一遍，判断这段能否支撑某条要点。不合适的窗口直接弃用，例如某条要求"章内有 ≥30 字实物描写"，第一版选的窗口全是角色在解释设定，只能换掉。

### 4. 逐字核验

生成文档后，用脚本把每一行 `> ` 引用去空白，与三卷原文拼接串做子串比对。

当前状态：`style.md` 390 行、`voice.md` 429 行、`title.md` 278 行、`flashback.md` 439 行、`structure.md` 30 行——**合计 1,566 行，missing = 0**。

### 5. 配额

由于三部的篇幅不等，文风和写法也有细微差别，所以大致按 5:3:2 的精力权重落实示例配额（第三部 / 第二部 / 第一部）：

| 文件             |   第三部 |   第二部 |   第一部 |
| -------------- | ----: | ----: | ----: |
| `style.md`     | 54.1% | 26.3% | 19.6% |
| `voice.md`     | 51.8% | 28.4% | 19.9% |
| `title.md`     | 54.9% | 28.4% | 16.7% |
| `flashback.md` | 55.6% | 27.5% | 17.0% |

## 实际生成示例

以下内容生成模型：**DeepSeekV4.1Flash - 1017**，使用平台：**DeepSeek Harness**。

提示词：写一段关于路明非和绘梨衣的互动场景，300字左右，其余无要求。

>便利店的自证贩售区只剩一台机器还亮着，路明非蹲在自己机器的出餐口前往里看。第四枚铁皮徽章在托盘口卡住，一半伸在外面，一半卡在里面。

>“又卡住了。”路明非说，“这台机器只负责提供娱乐，不负责给人用的乐趣？”

>绘梨衣蹲在旁边，两只手抱着便利店买的热可可，看着他。

>“看我也没用啊。”路明非用力拍了拍机身，“我不是维修工，我是客人。”

>机器仍然不动。绘梨衣把热可可放在地上的塑料袋上，走到出餐口前，也蹲下，往里看。她的眼睛贴得离出餐口太近，灯光映在她的瞳孔上，像两块光滑的玻璃。

>她伸出手，两根手指伸进出餐口，把徽章拨了出来。

>动作非常熟练。路明非觉得这种熟练好像不太对。

>绘梨衣把徽章放进他手心里，回到自己的位置，重新抱起热可可。她的呼吸在刚才动作时略微急促了一点，很快又均匀。

>路明非低头看那枚徽章，上面印着一只戴墨镜的企鹅，旁边有个很俗的单词。“就这东西卡了我们俩七分钟。”他说。

>绘梨衣点点头。

>“你不会是专门练过从卡住的自动贩卖机里掏东西的吧？”路明非忽然问。

>绘梨衣从风衣口袋里摸出一个小本子和一支笔，在上面写了一行字，把纸页翻给他看。

>“以前在家里也卡住过。”

>下面还有一行很小的字：“从来没成功过。”

>路明非看了两遍，把这句诚实得过分的话读了出来。

>绘梨衣点了点头，没有笑。

>“那你刚才怎么就这么顺手？”路明非问。

>她又写：“因为这次你蹲在旁边。”

>路明非的手停在半空。便利店的日光灯管嗡嗡作响，冰柜压缩机“咚”地响了一声，随后又安静下去。

>他低头看了看那枚徽章，把它举起来，对着灯照了照，说：“谢谢。分你一半。”

>绘梨衣接过话，根本没说什么；她伸出两根手指，把企鹅徽章从他手心里拿走，又放回他的手心里——像把一个东西还回去，只是为了让他再递一次。

>路明非只好重新递给她。绘梨衣把徽章放进热可可旁边那个塑料袋的侧袋里，拉上拉链。

>“放这么深，是怕它再卡住？”路明非说，“还是怕我抢回来？”

>绘梨衣看了一眼自己的塑料袋，又看了一眼他，慢慢站起来。

>“走吧。”路明非说，“反正卡住的也不是我们。”

>他走在前面，听见后面传来塑料袋轻轻摩擦的声音，很规律，每走三步响一次。

## 已知限制

- 统计基于旧版《龙族》原文，且使用单一电子版文本。不同版本的标点、分段可能略有差异，绝对数值会浮动，但比例关系稳定。
- 词频统计只覆盖规则里具体要求的小部分词汇，不是全词表。
- 规则由读者认可度更高的前三部推导得出。《龙族四：奥丁之渊》《龙族五：悼亡者归来》未引用进语料库。
