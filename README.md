# longzu · 龙族文风写作 Skill

把江南《龙族》三部曲的写作规律，解析成一套**可以对照检查**的操作项。

学习内容来自《龙族》前三部约180w字的内容，并进行了详细数据解析。

附带 **121 条要点**、**62 项自检清单**、**1,566 行逐字原文引用**。

---

## 这是什么

一个给长篇小说写作 AI（或人）用的**风格规格书**，负责回答三种问题：

1. **动笔前**：这一章该怎么起名、第一段怎么写、对白占多少、章末怎么结尾。
2. **写的时候**：这个词是《龙族》里会出现的吗？这句该长还是该短？这段玩笑是不是太扁平？
3. **写完改稿**：为什么"句子都对但不像"？为什么高潮不燃？为什么插叙读起来像资料？

## 这不是什么

- **不是**《龙族》的同人续写模板。它提供规则而非句子。
- **不是**文学评论。每条判断背后都有一个可核对的数字，或一段可查证的原文。
- **不包含**原著正文。仓库里只有用于论证规则的引用片段，没有整章文本。

## 用法

`SKILL.md` 里的流程是七步：

1. **定卷位** — 这段文字在第一部、第二部还是第三部的气质上（三部的句子长度差 34%，定错全歪）
2. **搭骨架** — 五段式 + 8 行速查表
3. **定章名、写章首** — 标题四步法 + 章首六型钩子
4. **写主体** — 对白比例、跑题节奏、长段配额；写往事时转 `flashback.md`
5. **写高潮** — 五拍结构 + 打斗句配比
6. **写章末** — 四型落点，只用一个
7. **回收伏笔** — 信息差三格 + 回收节奏

写完后对照 62 项自检清单排查，有不符合要求的时候就回去改。改不动的时候查 `SKILL.md` 末尾的**崩坏修法表**（16 行症状 → 修法）。

## 方法论

所有条目都来自同一套流程，可以复现：

### 1. 语料转换

三部 txt（GBK）→ UTF-8 Markdown。统一去空行、`# 书名`、`## 章节标题`、正文每段后加空行。

**校验**：md 数与 txt 数一致；三份文件的 U+FFFD 计数均为 0（无乱码）；首尾完整。

### 2. 段落索引

由于行号漂移，所以所有定位都用**正文段落数组索引**——排除空行、书名行、标题行后的第 N 段。标题行另存一张表（原始行号 + 标题文本），用来检查某段属于哪一章。

这一步踩过的坑值得记下来：某版脚本顺手跳过了 `[1]` 脚注行，导致第三部段落数从 14867 变成 14815，章节反查整体错位，取到的"须弥座誓师"其实是第十四章开头。

### 3. 提取与取样

- **词频/密度统计**：对三卷分别计数，换算成"每万字频次"，再横向对照。
- **窗口取样**：按段落索引切出 150–2,000 字的连续片段，人工读一遍，判断这段能否支撑某条要点。不合适的窗口直接弃用——例如某条要求"章内有 ≥30 字实物描写"，第一版选的窗口全是角色在解释设定，只得换掉。

### 4. 逐字核验

生成文档后，用脚本把每一行 `> ` 引用去空白，与三卷原文拼接串做子串比对。

当前状态：`style.md` 390 行、`voice.md` 429 行、`title.md` 278 行、`flashback.md` 439 行、`structure.md` 30 行——**合计 1,566 行，missing = 0**。

### 5. 配额

按 5:3:2 的精力权重落实示例配额（第三部 / 第二部 / 第一部）：

## 依靠数据分析的部分结论

写进文档之前，这些数字都先在原文里数过一遍。

**越往后越冷静。** 平均段长 51.1 → 64.0 → 76.0 字；平均句长 23.3 → 25.3 → 31.2 字；极短句（≤6 字）占比 18.4% → 13.2% → 9.7%；省略号每万字 30 → 32.3 → 13.1 次；语气词每万字 96.3 → 93.9 → 72.8 次。第一部靠密集对白和省略号推进，第三部靠长句和留白。

**比起"突然"，江南更偏好“忽然”一词。** 全书 `忽然` 出现1,223 次，`突然` 仅11 次。比例 111:1。

**江南不写"他回忆起"。** 第三部每万字"照片/档案/报告/本子"3.1 次，而"记得/回忆起"只有 1.6 次。进入过去的主门是"找到一份东西"，辅门才是回忆。

**几乎不写"回到现在"。** 三卷合计，"回过神来/这才意识到/回到现实"只有 16 次。从过去回到当下，靠的是一句对白、一个动作、一个独立短段。

**"多年以后"是第三部才解锁的。** 预叙标记：第一部 0 次，第二部 1 次，第三部 16 次。

**标题大多不点题。** 90 个有题章节里，标题词在正文中出现的只有 37 章（41.1%）；出现的那些，首现位置平均在章节 38.4% 处，压在中后段当一记台词，而不是首段点题。

**4 字题占三成。** 29/90（32.2%），其中 19 条纯并列、10 条夹一个虚词。全书标题不含任何阿拉伯数字。

**脏话有配额，也归属明确。** 每万字 4.7 / 6.3 / 5.4 次；其中归属主角路明非的占 54% / 33% / 29%。正式场合零脏话。

**每个角色有专属的心理装置。** 路明非用烂话、楚子航用精密比喻、恺撒用宣言体、源稚生把感动当场打折、绘梨衣零台词只靠动作。串味是最常见的崩坏。

## 已知限制

- 统计基于旧版《龙族》原文。
- 统计基于单一电子版文本，不同版本的标点、分段可能略有差异，绝对数值会浮动，但**比例关系稳定**。
- 词频统计只覆盖规则里具体要求的小部分摧毁，不是全词表。
- 规则由前三部推导得出。《龙族四：奥丁之渊》《龙族五：悼亡者归来》未引用进语料库。
