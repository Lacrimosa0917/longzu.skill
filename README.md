## 作者的碎碎念

高中的时候看了三遍龙族，包括新旧两版和龙四龙五，对江南老贼可谓又爱又恨。每一个衰小孩大概都共情过路明非，也羡慕他有拯救世界的精彩故事。

至今为止，我对《龙族》的笔法印象依旧很深，而且一直学不会，只好希望能寄托在AI身上了。于是给AI喂了龙族前三部的正文，蒸馏出了这个skill，迭代了几版，最终有了现在这个仓库。

它依旧有很多不足，更不可能完全模仿江南，只能用数据去分析那些感性的东西，试着去拼凑一段有“龙族味”的文字。

如果你觉得它还不错，可以给仓库点一个star。如果你有余裕，也可以贡献一些你的数据。如果有不满意的地方，也可以提出你的意见。

**本skill持续更新中，我会努力把它做到最好。**

> **我们都是小怪兽，有一天会被正义的奥特曼杀死**。

## 功能

这是一个AI agent skill，更具体地说，是一个给小说写作 AI 使用的**风格规格书**，负责三个环节：

1. **动笔之前**：整体的结构与规划。
2. **写的时候**：实时的对照与修正。
3. **写完改稿**：完善的检查与润色。

- **不是**《龙族》的同人续写模板。它只提供写作规则，不包含任何可以直接使用的句子/文段。
- **不是**《龙族》续写专用的技能。它只记录了江南写作的方法，**没有对《龙族》的剧情、人设、世界观进行任何解析**（如果你用它续写《龙族》，大概率会有很多问题）。
- **不是**文学评论。它不对《龙族》进行任何评判，只使用客观的、可复现的统计口径与比例关系来支撑判断。
- **不包含**原著正文，也不包含原文引用片段。公开分发的 `references/` 已按版权要求删除全部逐字引文，只保留从语料中统计出来的数字、比例和可执行的写作规则。想要对照原文，请自备语料在本地复现统计。

## 安装方法

这个 skill 使用通用的 `SKILL.md` + `references/` 结构，任何支持 skill 的 agent 环境都能读。

**DeepSeek Harness**

```bash
cp -r longzu ~/.dsh/skills/
```

**Claude Code / 其它支持 skills 的环境**

```bash
cp -r longzu ~/.claude/skills/
```

或者更简单，直接将仓库地址 **https://github.com/Lacrimosa0917/longzu.skill** 发送给agent，让他给你安装。

装好后，在提示词里写："按江南的风格写一章""这段像不像龙族""帮我起个章名"时，agent 会自行加载 `SKILL.md`，并按需读 `references/` 里的对应文件。

## 构建方法

所有条目都来自同一套流程，可以复现：

### 1. 语料转换

使用语料为《龙族》三部正文的txt文件，由AI进行 txt（GBK）→ UTF-8 Markdown 格式转换。统一去除空行、`# 书名`、`## 章节标题`、正文每段后加空行。

**校验**：md 数与 txt 数一致；三份文件的 U+FFFD 计数均为 0，确认无乱码；首尾完整。

### 2. 段落索引

由于行号漂移，所以所有定位都用**正文段落数组索引**来排除空行、书名行、标题行后的第 N 段。标题行另存一张表（原始行号 + 标题文本），用来检查某段属于哪一章。

### 3. 提取与取样

- **词频与密度统计**：对三卷分别计数，换算成"每万字频次"，再进行横向对照。三卷去空白字数分别为 261,494、410,290、1,130,091，合计 1,801,875 字。
- **窗口取样**：按段落索引切出 150–2,000 字的连续片段，人工读一遍，判断这段能否支撑某条要点。不合适的窗口直接弃用，例如某条要求"章内有 ≥30 字实物描写"，第一版选的窗口全是角色在解释设定，只能换掉。取样只用于确认规则是否成立，成品里不留原文。

### 4. 规则化

每条要点写成两段：**写法**（可直接执行的指令，带具体数字或句式模板）和**验收**（一条能判对错的检查条件）。统计无法支撑的判断没有写入；不包含"语言优美""氛围浓厚"这类无法验收的笼统词汇。

此仓库分发的版本在这一步之后删去了全部逐字引文，只保留写法、验收与统计数字。所以你读到的每一条都能独立执行，但文件内没有用于参考的原文。

### 5. 配额

三部篇幅不等，写法也有细微差别，所以按 5:3:2 的精力权重落实规则密度（第三部 / 第二部 / 第一部）。下表是各文件在内部版本里的示例字数占比，公开版的规则条目仍按这个权重写成，只是引文已移除：

| 文件             |   第三部 |   第二部 |   第一部 |
| -------------- | ----: | ----: | ----: |
| `style.md`     | 54.1% | 26.3% | 19.6% |
| `voice.md`     | 51.8% | 28.4% | 19.9% |
| `title.md`     | 54.9% | 28.4% | 16.7% |
| `flashback.md` | 55.6% | 27.5% | 17.0% |

如果你在本地补回语料并重新取样，建议先跑一遍逐字核验（把每条引文去空白后与三卷原文拼接串做子串比对，missing 必须为 0），再算占比，不要凭印象填。

`craft.md` 与 `negative.md` 不在配额表里：前者不含统计，来源是逐段通读，只有取材偏向（24 条里取材自第三部 13 条、第二部 6 条、第一部 5 条）；后者是"零次即达标"的清单，某一词在全书出现几次比它占多少篇幅更有意义，所以每条都直接标了实测次数。

`lexicon.md` 采取另一套规则：它统计的是每个词的全书总次数、每万字频次、所在段落的平均长度、对白占比与共现率，用来判断"这个词能不能放在这里"。词表本身的选取兼顾三卷，不按上述权重分配。

## 实际生成示例

以下内容生成模型：**DeepSeek-V4.1-Flash-1017**，使用平台：**DeepSeek Harness**。

提示词：用该skill写一段文字，不做任何要求，300字左右。

实际输出 14 段、360 字（去空白），下列为全文照录，进行一轮AI自改。使用版本为1.5.0，仅供参考。

>地铁末班车十一点五十八分从赤坂见附开出。所谓末班车，不是最后一班车，是最后一班你还舍得坐的车。过了这一班，出租车起步价七百三十円，跳表比心跳还快。

>"关门了。"值班员隔着玻璃说。

>"我知道。"
>
>"那你还站着。"
>

>
>出口台阶上坐着一个人，旧夹克，抱着个纸袋。甜味从袋口漏出来，是罗森八点以后打对折的那种蛋糕，奶油已经有点塌了。

>那人把纸袋往台阶中间推了推。路明非摆手："不用。"他也不客气，自己拆开，塑料叉子切下一块，举在两个人之间，一直举着。

## 原文段落库

依靠数据生成的规则不总是那么有效，这时候可以提供一些原文语料进行参考。

本skill为你预留了添加原文段落的路径，你可以便捷地向其中添加你认为有参考价值的段落。`references/passages/` 是预留的添加原文参考段落的文件夹。

> 当前分发版本里已移除了原文文件。如有需要，请先阅读 `references/passages/README.md` 并按照使用说明创建文件并自行添加语料，以下只提供最简单的使用说明。

文件格式：每段分为四个板块：标题、两行元信息（来自哪卷哪章、类型关键词）、原文文段、几条"可以注意的地方"。需要添加时，只需要接着数字往下添加即可。本仓库提供了一份 19 段的目录（P01–P19），是AI学习得出的几个可能常用的场合，你可以按照这个骨架建立，也可以按自己的想法来。

## 反馈闭环

skill主体成型后，新引入了反馈闭环来进行优化。

运行机制很简单，你也可以让你的agent在本地进行。由agent使用skill生成一段文字，再从原文截取三段，四段一起交给一个子代理进行盲测，找到“不一样”的那一段并指明原因。

子代理的反馈返回到agent后，按反馈优化skill并重新开始下一轮。
